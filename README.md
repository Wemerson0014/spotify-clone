Este é um projeto de estudo desenvolvido para replicar a interface e a experiência de usuário do Spotify Web Player. O foco principal foi dominar o uso do **Tailwind CSS** para estilização rápida e responsiva, além de aprofundar conceitos de **componentização em React**.

---

## 🚀 Funcionalidades

- **Interface Responsiva:** Adaptada para diferentes tamanhos de tela.
- **Sidebar & Navegação:** Menu lateral fixo com acesso rápido à Home, Search e Library.
- **Player de Música:** Barra inferior com controles de reprodução (Play, Pause, Progress Bar, Volume).
- **Grid de Playlists:** Layout dinâmico para exibição de álbuns e artistas.
- **Efeitos Hover:** Interatividade realista com botões de play e cards.

---

## 🛠️ Tecnologias Utilizadas

As seguintes ferramentas foram usadas na construção do projeto:

- [React.js](https://reactjs.org/) - Biblioteca para construção da interface.
- [Tailwind CSS](https://tailwindcss.com/) - Framework CSS utilitário para design moderno.
- [Lucide React](https://lucide.dev/) - Biblioteca de ícones leves e elegantes.
- [Vite](https://vitejs.dev/) - Bundler rápido para o ambiente de desenvolvimento.

```bash
